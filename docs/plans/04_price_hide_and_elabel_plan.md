# 미로그인 가격 비공개 및 전자라벨 연동 구현 계획서

본 계획서는 미로그인 시 가격 노출 방지(UI 변경)와 외부 전자라벨 사이트(e-label-lyart.vercel.app) 연동을 위한 상세 구현 내용을 담고 있습니다.

## ⚠️ User Review Required (사용자 검토 필요)
- 전자라벨 사이트를 모달(팝업) 안에 띄울 때, **각 화장품별로 바로 해당 제품 화면이 나오게 하려면 제품별 정확한 인터넷 주소(URL)가 데이터베이스에 등록되어 있어야 합니다.** 
- 현재는 제품별 URL 정보가 없으므로, 전자라벨 첫 화면(메인)이 뜨게 연결해두는 방식으로 구현할 예정입니다. 이 방식이 괜찮으신지 확인 부탁드립니다.

## Open Questions (제니님께 드리는 질문)
1. 미로그인 시 장바구니 하단의 **"총 결제 금액"**도 숨길까요, 아니면 로그인 시에만 장바구니 담기가 가능하도록 아예 장바구니 기능을 잠글까요? (현재 계획은 담을 수는 있지만 총액은 "로그인 후 확인"으로 가려두는 방식입니다)
2. 상품별로 🔍 [상세정보(전자라벨)] 버튼을 누르면 화면 가운데에 모달창(작은 팝업)으로 띄워드릴 예정인데, 혹시 아예 새 탭(새 창)으로 열리는 걸 선호하시나요?

## Proposed Changes (수정될 파일 및 내용)

### 1. `Home.jsx`
- `ProductList`와 `Cart` 컴포넌트에 현재 접속 중인 사용자가 누구인지(`user` 정보)를 전달하도록 수정.
- 외부 사이트(전자라벨)를 팝업으로 띄우기 위한 `iframe 모달` 렌더링 로직 추가.

### 2. `ProductList.jsx`
- 로그인되지 않았을 경우(`user`가 없을 경우), 상품 카드의 가격(예: 6,500원) 대신 "로그인 후 확인" 등의 안내 문구 표시.
- 로그인되지 않았을 경우, 하단의 '구매 대상별 단가표'를 완전히 숨기고 "로그인 하시면 상세 단가표를 확인하실 수 있습니다"라는 안내 박스로 대체.
- 각 상품별로 **[🔍 전자라벨 보기]** 버튼 추가 (클릭 시 Home.jsx의 모달 호출).

### 3. `Cart.jsx`
- 로그인되지 않았을 경우, 장바구니 내 개별 상품 가격 및 하단의 총 결제 금액을 마스킹 처리("로그인 필요").

## Verification Plan (검증 계획)
### 수동 검증
1. **로그아웃 상태 테스트:** 사이트 접속 시 단가표가 안 보이는지, 상품 카드의 가격이 숨겨지는지, 장바구니 총액이 안 보이는지 테스트.
2. **전자라벨 팝업 테스트:** 상품 카드에서 🔍 버튼을 클릭했을 때 모달창 안에 `e-label-lyart.vercel.app` 사이트가 이탈 없이 잘 뜨는지 테스트.
3. **로그인 상태 테스트:** 사번으로 로그인했을 때 예전처럼 가격표와 총액이 정상적으로 모두 보이는지 테스트.
