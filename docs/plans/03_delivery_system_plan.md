# 배송 신청 기능 구현 계획서 (Delivery System Plan)

제니트리 화장품 복지몰에 **수령 방법(방문 수령 / 택배 배송) 선택 및 배송지 입력 기능**을 도입하기 위한 작업 계획입니다. 이 작업은 데이터베이스(Supabase) 구조 변경과 주문 프로세스 UI의 큰 변화를 수반하므로, 진행 전 제니님의 확인과 승인이 필요합니다.

## User Review Required
이 기능은 데이터베이스(Supabase) 테이블 구조 변경이 필요합니다. 승인해주시면 제가 제니님이 직접 Supabase SQL Editor에 복사해서 넣으실 수 있는 쿼리(명령어)를 제공해 드리겠습니다.
또한, 배송비와 주소 입력 방식에 대해 제니님의 정책 결정이 필요합니다. 아래 **Open Questions**를 꼭 확인해 주세요!

## Open Questions

본격적인 코드 작업 전에 다음 두 가지 사항을 어떻게 할지 알려주시면 감사하겠습니다!

1. **배송비 정책 🚚**
   - 택배 배송을 선택할 경우 **배송비(예: 3,000원)**를 총 결제액에 자동으로 합산할까요?
   - 아니면 복지몰 특성상 전면 **무료 배송**이거나 **착불**로 진행할까요?

2. **주소 입력 방식 🏠**
   - "다음(Daum) 우편번호 검색창"을 붙여서 우편번호를 검색하게 만들어 드릴까요? 
   - 아니면 직원들이 쓰는 거니까 간단하게 **직접 타이핑해서 주소를 적는 빈칸(텍스트 박스)**만 두 개(기본주소, 상세주소) 만들어 둘까요?

## Proposed Changes

### 1. Database (Supabase)
기존 `orders` 테이블에 배송 관련 정보를 저장할 빈칸(컬럼) 5개를 추가합니다.
- `delivery_type` (수령방법: '방문수령' 또는 '택배배송')
- `delivery_name` (수령인 이름)
- `delivery_phone` (수령인 연락처)
- `delivery_address` (배송지 주소)
- `delivery_memo` (배송 요청사항)

*(제가 생성해드릴 005_add_delivery_columns.sql 파일을 Supabase에서 실행하시면 됩니다.)*

### 2. Frontend (React UI)

#### [MODIFY] `src/pages/Home.jsx`
- **주문 확인 모달 (`showAuthModal`) 확장**:
  - 기존에는 "최종 주문 접수하시겠습니까?" 텍스트만 있었으나, 여기에 **수령 방법 선택 (라디오 버튼)** 추가.
  - '택배 배송' 선택 시 아래로 스르륵 열리는 **배송지 정보 입력 폼(수령인, 연락처, 주소, 요청사항)** 추가.
- **주문 처리 로직 (`processOrder`) 수정**:
  - 주문 접수 시 입력받은 배송지 정보를 Supabase `orders` 테이블에 함께 저장.
  - (결정된 정책에 따라) 배송비 합산 로직 추가.
  - 텔레그램 및 이메일 알림 내용에 **수령 방법 및 배송지 정보** 추가 포함.
- **관리자 주문 현황 패널 업데이트**:
  - 관리자가 주문 내역을 볼 때 "방문수령"인지 "택배배송"인지 뱃지로 명확히 표시.
  - 택배 배송인 경우, 클릭해서 배송지 정보를 확인할 수 있는 영역 추가.

## Verification Plan
1. Supabase 컬럼 추가가 정상적으로 되었는지 주문 테스트 진행.
2. 장바구니에서 '방문 수령'과 '택배 배송'을 각각 선택하고 주문했을 때 폼과 총액이 올바르게 반응하는지 확인.
3. 텔레그램 및 이메일 영수증에 배송지 정보가 예쁘게 잘 들어오는지 최종 확인.
